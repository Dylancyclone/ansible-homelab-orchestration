Unpackerr extracts archived downloads (RAR, ZIP, 7z and others) for Sonarr, Radarr and Lidarr. When a finished download in an app's queue only contains archives, Unpackerr extracts it in place so the app can import it, then removes the extracted files once the import is done.

## Setting up

```yaml title="inventories/homelab/group_vars/homelab.yml"
unpackerr_enabled: true
unpackerr_sonarr_api_key: "your_sonarr_api_key"
unpackerr_radarr_api_key: "your_radarr_api_key"
unpackerr_lidarr_api_key: "your_lidarr_api_key"
```

Each API key is found in that app under Settings > General > API Key. Only the apps with an API key set are watched, so leave out any you don't use.

Unpackerr has no web interface. Check `docker logs unpackerr` to see what it is extracting.

## Configuration

See the default configuration options for Unpackerr at [`roles/unpackerr/defaults/main.yml`](https://github.com/Dylancyclone/ansible-homelab-orchestration/blob/main/roles/unpackerr/defaults/main.yml).
Add any overrides to your `inventories/[your_inventory]/group_vars/homelab.yml` file.

Unpackerr mounts the downloads directory at `/downloads`, the same path Sonarr, Radarr and Lidarr use, so the paths they report line up. If you change any of their download directories, set `unpackerr_download_directory` to match.
